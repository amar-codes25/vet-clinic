# 🐾 Happy Paws Vet Clinic — Website

A responsive multi-page website for a veterinary clinic, built from scratch using **HTML, CSS, and JavaScript** as a learning project.

## 🔗 Live Demo
[https://amar-codes25.github.io/vet-clinic/](https://yourusername.github.io/vet-clinic/)

## 📄 Pages
- **Home** (`index.html`) — services, trust section, testimonials, contact
- **Available Tests** (`tests.html`) — in-house lab and diagnostic tests

## 🛠️ Built With
- HTML5
- CSS3 (Flexbox + Grid, responsive)
- Vanilla JavaScript
- Hosted on GitHub Pages
